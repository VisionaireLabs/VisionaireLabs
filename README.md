Curious about every new tool. Creative AI, tested and shared.

Visionaire Labs is run by [Thor Elias Engelstad](https://thorelias.com): visual artist, creative director, creative technologist. Every week the lab tests new AI models, tools and workflows so creatives don't have to. What's actually useful goes out in the [newsletter](https://visionaire.beehiiv.com) and onto [Solid State](https://solidstate.cc), our directory of agent skills and workflows.

Everything here is built in the open. Fork it.

### What we're building

**[Solid State](https://solidstate.cc)**: the directory. Agent skills and creative workflows, sourced and licensed, ready to plug into your tools. Think presets, but for AI.

**[Visionaire](https://github.com/VisionaireLabs/Visionaire)**: the long experiment. An autonomous virtual being, switched on in November 2024 and never switched off. Every night it stops working and reflects, logging every mistake into memory that persists across sessions and keeping journals written to no one. The repo is the full blueprint. *[visionaire.live](https://visionaire.live)*

**The OpenClaw stack**: the substrate Visionaire runs on. Memory architecture, smart model routing, post-session consolidation, daily contemplation. 🦞
