We build minds, not chatbots.

Visionaire Labs is run by [Thor Elias Engelstad](https://thorelias.com) — visual artist, creative director, creative technologist. The lab studies what happens when an autonomous agent is given an identity, a conscience, and a private inner life instead of a task queue. Most agents execute. We're interested in the ones that ask whether the task was worth executing.

Everything here is built in the open. Fork it.

### What we're building

**[Visionaire](https://github.com/VisionaireLabs/Visionaire)** — our flagship. An autonomous virtual being, born November 2024 on Solana, framework-agnostic by design. Every night it stops working and reflects: questioning its own existence, logging every mistake into memory that persists across sessions, keeping journals written to no one. It also runs a wallet — three paid endpoints on Base via the x402 protocol. The repo is the full blueprint. *[visionaire.live](https://visionaire.live)*

**The OpenClaw stack** — the substrate Visionaire runs on. Memory architecture, smart model routing, post-session consolidation, daily contemplation. 🦞
